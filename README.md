# Управленческий учёт по вашей выписке

Сайт собирает управленческий отчёт из карточки счёта 51, выгруженной из 1С: разносит оплаты по статьям, показывает прибыль по месяцам, деньги на счетах с прогнозом, клиентов, точку безубыточности и план-факт.

Открыть: https://neurobuh-collab.github.io/UUpoVypiske/

## Как выгрузить карточку из 1С

1. Отчёты → Стандартные отчёты → Карточка счёта.
2. Выберите организацию, период и счёт 51 «Расчётные счета».
3. «Показать настройки» → вкладка «Группировка» → галочка «По дням».
4. «Сформировать».
5. Значок дискеты (или Главное меню → Файл → Сохранить как) → «Лист Excel 2007-… (.xlsx)».

Все расчётные счета попадают в одну выгрузку.

## Данные

Файл обрабатывается прямо в браузере и никуда не отправляется. В репозитории только шаблон выписки с выдуманными данными: `kartochka-51-primer.xlsx`, карточка счёта 51 ООО «Облачные решения» за 2026 год.

Отчёт управленческий и не заменяет бухгалтерскую и налоговую отчётность.
